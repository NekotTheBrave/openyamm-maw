# Decoration placement checks

The restored 2x sprite pack `assets_dev/engine/decorations_x2/` and its audit tool
(`tools/audit_decoration_placement.py`) were removed on 2026-10-19: decorations draw 3D models, items on the ground
draw 3D models and projectiles draw effects, so nothing drew the pack any more. Both remain in git history; the
original BMPs remain in `assets_dev/_legacy/sprites_original/`. The notes below are kept as history.

## Emerald Island regression, 2026-10-07

Both reported sprites retain their original anchors: `7rock08_p2.png` differs by only half a native pixel;
all eight `dec64*_p996.png` pedestal frames have zero bottom-margin drift. Their floating came from terrain
cells being triangulated across the opposite diagonal from the native ODM geometry.

| Entity | Position | Previous rendered ground | Correct native ground |
| --- | --- | --- | --- |
| 10, `7rock08` | (16736, 7376, 30) | 0 | 30 |
| 146, `dec64` | (2395, 9065, 969) | 912.8125 | 969.4375 |

Rendering, height/normal sampling, movement, navigation, terrain picking, editor previews and future lighting
bakes now use the native top-left to bottom-right diagonal. Existing baked lighting was not regenerated by
this geometry fix; a rebake updates its terrain shading and shadows to the corrected geometry.

Repeat the two supplied camera views with the native capture tour:

```sh
./tools/run_game.sh --isolated decoration-placement --world mm7 --map 7out01.odm --warmup 0 --seconds 30 \
  --set debug.screenshot_tour_path="$PWD/tools/screenshot_tours/mm7_decoration_placement.yml"
```

Regression tests cover the two native support heights, both triangles' normals, non-planar navigation
floors and movement beside cliffs. The bitmap audit's test checks deliberate native padding, a raised
restored base, a changed canvas, manifest drift and original filenames with uppercase letters.
